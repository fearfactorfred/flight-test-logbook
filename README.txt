FLIGHT TEST LOGBOOK PRO — NO-MAC IPHONE DEPLOYMENT

Upload all four files to any HTTPS static web host:
 index.html
 manifest.webmanifest
 sw.js
 icon.svg

Then open the HTTPS address in Safari on iPhone:
Share -> Add to Home Screen -> Add.

The app works offline after the first successful load and stores data locally on the device.
Use Export Backup regularly.

Features:
- Test programs
- Test days
- Aircraft configurations
- Flight timer and flight logs
- GPS capture
- Test cards
- Point-by-point execution
- PASS / PARTIAL / FAIL / ABORT / N/A
- Automatic discrepancies
- Corrective action notes
- End-of-day report
- Print / Save PDF
- JSON backup/restore
